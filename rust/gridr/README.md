# gridr

Rust core of [GridR](https://github.com/CNES/gridr), a raster resampling and
filtering library developed at CNES.

It provides grid-based resampling, interpolators (nearest, linear, bicubic,
B-spline) and grid geometry tools. It has no PyO3 or NumPy dependency.

Python users should install the `gridr` package from PyPI instead.

The API is not stable yet. Breaking changes can happen in any 0.x release.
